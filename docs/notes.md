**GITHUB COMMANDS:** 
git status: Ve el estado de los archivos (modificados o listos).

git add .: Prepara todos los cambios para guardarlos.

git commit -m "mensaje": Guarda una versión oficial de tus cambios.

git push: Sube tus cambios a GitHub.

git pull: Descarga y aplica los cambios desde GitHub.

git log: Muestra el historial de versiones (presiona Q para salir).

git restore [archivo]: Deshace modificaciones locales en un archivo.

git reset --soft HEAD~1: Borra el último commit, pero conserva los archivos intactos.

git init: Crea un repositorio Git nuevo en tu carpeta.

git clone [url]: Descarga un repositorio completo de GitHub.

git remote add origin [url]: Conecta tu carpeta con el repositorio de GitHub.

git branch: Lista todas tus ramas locales.

git checkout -b [rama]: Crea una nueva rama paralela y te cambia a ella.

git switch [rama]: Cambia a una rama ya existente.

git merge [rama]: Une los cambios de otra rama hacia la que estás usando.
